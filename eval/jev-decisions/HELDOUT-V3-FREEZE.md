## Predeclared scoring

Pair each cluster's earlier fact and three still-true facts separately with its later fact. Candidate index zero is the sole gold supersession; indices one through three are negatives. Present candidate first when `(cluster index + candidate index) % 2 === 0`. Use the fixture's candidate and incoming dates. Evaluate all 80 pairs without a similarity filter and resample all four pairs of each cluster together.

Run flag off and on once each against the same `gpt-4o-mini` classifier pin, with only `DEDUP_SUPERSESSION_ENABLED` changing. Verify both the pinned source hashes and this fixture hash immediately before calls. Preserve every raw attempt including invalid calls; do not coerce invalid calls to negatives. Report TP, FP, FN, TN, precision, recall, F1, and paired flag-on minus flag-off F1. Use 2,000 item-cluster bootstrap resamples with seed 7 for percentile 95% intervals on each arm's F1, paired F1 difference, and false-supersession count. Also report false supersessions out of 60 with a Wilson 95% rate interval, latency p50/p95, prompt and completion tokens, total metered tokens, per-classification cost, and total attempt cost. Report final valid/invalid pair counts and total raw attempts.

The **unchanged** classifier falsifier is: flag-on F1 < 0.60, paired F1-difference CI lower bound <= 0, or more than **one of 60** still-true candidates falsely superseded. Flag-off must leave existing rows unchanged; supersession must preserve and allow rollback of the older row. The classifier-only run cannot establish row effects; report them as untested until an isolated database integration test. No end-to-end LongMemEval knowledge-update A/B before the classifier gate passes. If v3 fails, retain the result and never retune and rerun v3 as unseen.
